# Pedram — Developer Portfolio

Personal portfolio for [pedicore](https://github.com/pedicore), built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in your browser. No build tools are required. The site uses Google Fonts when internet is available and system fallbacks otherwise.

## Deploy with GitHub Pages
1. Upload `index.html`, `style.css`, and `script.js` to the **root** of the `pedicore/pedicore.github.io` repository on the `main` branch.
2. Go to **Settings → Pages** in that repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`. Save.
4. Wait for GitHub to publish the site at https://pedicore.github.io/.
