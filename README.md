# Pedram — Developer Portfolio (v2)

A responsive, animated personal portfolio built with plain HTML, CSS, and JavaScript. Designed for GitHub Pages.

## Publish

1. Upload `index.html`, `style.css`, and `script.js` to the **root** of the public repository `pedicore/pedicore.github.io`.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
3. Wait for the deployment to finish under **Actions**, then visit https://pedicore.github.io/.

## Features

- Dark blue visual theme with CSS-based project artwork
- Animated ticker, floating terminal, subtle star pattern, scroll reveal and progress indicator
- Responsive layouts for mobile and desktop
- Reduced-motion accessibility support
- No external dependencies or image hosting requirements

## Update personal details

Edit the links and project descriptions in `index.html`. Keep project status labels accurate as work progresses.
